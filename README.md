# Prácticas asignatura Aprendizaje Automático


## Practica 1: Aprendizaje Supervisado
### Problema 1: Clasificación
> Uso de Inteligencia Artificial para el desarrollo de un clasificador que indique la categoría o gama a la que debería pertenecer un terminal móvil.
### Problema 2: Regresión
> Uso de Inteligencia Artificial para predecir la resistencia del hormigón. Se trata de modelar la relación entre la resistencia del hormigón (medida en MegaPascales, MPa), con respecto a diferentes variables relativas a la mezcla.
---

## Practica 2: Aprendizaje No Supervisado
### Problema 1: Agrupamiento
> Uso de Inteligencia Artificial para hallar categorías de tipos de clientes que compran en un centro comercial. Se trata de identificar cuántas categorías hay de clientes, así como sus características, que describan los distintos grupos de clientes que se pueden encontrar.
### Problema 2: Extracción de reglas de asociación
> Uso de Inteligencia Artificial para hallar correlaciones o dependencias entre las compras efectuadas en una tienda de comestibles. Se trata de identificar qué productos se suelen comprar juntos (itemsets frecuentes) y extraer reglas que ayuden a explicar el comportamiento de los clientes de forma automática.
---

## Practica 3: Aprendizaje Profundo
### Problema 1: Clasificación
> Uso de Inteligencia Artificial para poder identificar tipos de reseñas (positivas o negativas) con respecto a diferentes textos relativos a críticas de cine. Se trata de diseñar un modelo de Deep Learning que resuelva el problema, y hacer un análisis cuantitativo sobre la efectividad a la hora de clasificar una reseña.
### Problema 2: Autoencoders
> Uso de Inteligencia Artificial para eliminar el ruido existente en imágenes aprendidas por una red neuronal de tipo Autoencoder. Se trata de diseñar un modelo de Deep Learning que aprenda las características de todos los dígitos del 0..9 (conjunto de datos MNIST), y usar los embeddings para eliminar el ruido existente sobre la imagen de un nuevo dígito, donde el ruido se ha introducido previamente de forma artificial.
